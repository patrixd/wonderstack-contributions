# Code of conduct

This project is maintained by people in their spare time and used by people learning new tools. We want it to be a
friendly place for both.

## What we expect

- Be kind and assume good intent. Explain, don't scold — many contributors open their first pull request here.
- Review the change, not the person. Facts and sources settle disagreements; seniority does not.
- Keep it on topic: tools, training and how to describe them accurately.
- Respect privacy: never post personal data about anyone, including yourself, in files, issues or comments.

## What we do not accept

Harassment, insults, discriminatory language or imagery, sexualised content, threats, doxxing, spam, undisclosed
promotion of a product you are paid by, and attempts to game rankings or rewards.

If you work for a tool's maker, you are welcome to fix facts about it — say so in the pull request.

## Enforcement

Report problems to the maintainers listed in `.github/CODEOWNERS` or by e-mail to conduct@wonderstackai.com (read
only by the maintainers). We reply within a week and keep reports confidential. Consequences range from a private
note to a temporary or permanent ban from the repository. Moderation decisions can be appealed once, by e-mail, to a
maintainer who was not involved.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
